    Tests

    Write pytest tests that import from solution. Your code is saved as solution.py before each run.

    Python runs inside this browser tab. The first run downloads Python and pytest from jsDelivr, so you need internet and a few MB of data. The installable offline shell can reopen the interface after a first visit, but PDF/Python/OCR libraries and sign-in still require internet. Network use by your code is switched off as far as we can, but only run code you trust. The example tests call detect_ewma, so running them on the example Before code shows a real import error. Browser execution is not a hardened server sandbox: run only code you trust; very memory-intensive code can still slow or crash the browser.

    What leaves your device

    Your email address goes to our login service (Supabase). If you use Google, Google shares your name and email with it. A sign-in token stays in this browser until you sign out. Your current code, tests and extracted PDF text draft are automatically saved in this browser’s local storage; AI outputs and test-run history are not included in autosave. Clear it from Code → Clear workspace. PDFs, code and tests stay on this device unless you explicitly use AI Lab, which sends the first 18,000 characters of current PDF text, or the code/tests entered, to the configured AI provider after consent. The app does not save AI input/output history by default. The Account tab can export app-held account metadata or delete the Supabase account and linked app rows after confirmation; it does not automatically refund payments or delete records retained by external providers. Libraries for PDF reading, Python, OCR and sign-in are downloaded from public CDNs.
